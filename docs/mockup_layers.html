Как СТАЛО (сейчас): инструмент в трёх местах

GM-панель справа — program для SF2-частей
Layers — только DSP-пресет в строке, SF2-части без выбора
Дерево параметров — «Mode: SF2: SC-55 | program» ← неясно, что это
Один и тот же вопрос («чем играет эта часть?») отвечает в трёх местах по-разному.

Как ПРЕДЛАГАЮ: инструмент прямо в строке части

Layers — строка части = всё о раскладке и звуке части

A1 SF2: SC-55 prog 1 Mute Root DSP/SF2
A2 SF2: SC-55 prog 5 Mute Root DSP/SF2
A3 DSP prog — Mute Root DSP/SF2
Строка части = раскладка + инструмент + живые тумблеры. Один вопрос — один ответ: «чем играет эта часть и как».

Куда деваются остальные панели

GM-панель справа → браузер библиотеки: послушать инструменты, выбрать → «применить к выбранной части». Не редактор состояния.
Дерево параметров → остаётся, но привязывается к выбранной части: выбрал A2 в Layers → дерево показывает параметры A2. Заголовок дерева = имя части.
«Mode: SF2» из дерева исчезает — движок выбирается кнопкой DSP/SF2 в строке части.

Правило (как во всех DAW)

Строка части = ЧТО играет и КАК раскладано (инструмент, mute, root, диапазон, громкость)
Инспектор = ПОДРОБНОСТИ выбранной части (огибающие, фильтры, LFO, FX)
Docked снизу = ЧТО КРУТИТЬ ВО ВРЕМЯ ИГРЫ (транспорт, BPM, лупер, мьюты)

Один вопрос — одно место. Зеркала LED-консоли = слой «живого».
