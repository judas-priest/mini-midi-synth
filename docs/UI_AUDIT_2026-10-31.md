# UI Audit — 2026-10-31

Read-only аудит egui GUI. Платформа: egui-desktop (Linux/KWin Wayland, окно 1920×1036).
Кластеры: [top bar + part rows], [drum grid dock + looper], [pitch step sequencer],
[params editor + XY macros], [settings/audio + pad-perf + keybinds], [instrument browser modal],
[MIDI seq], [on-screen keyboard/pads + LED console].

Метод: 3 линзы (a11y/contrast, egui idioms, consistency) + якорная верификация на экране.
Скриншоты: `/tmp/s2.png`, `/tmp/z_parts.png`, `/tmp/z_grid_s.png`, `/tmp/z3_hdr.png`.

⚠ Часть состояний не воспроизведена на экране (lock-сессия + видеозвонок в процессе аудита) —
такие помечены `not screen-verified` / `code-verified`. Контраст посчитан по формуле sRGB,
не «на глаз».

## High

1. **Pitch Step Sequencer недостижим при 1920×1036 — обрезается docked-панелью барабанов, молча.**
   `draw_pitch_sequencer` — единственный в central без ScrollArea (`src/gui/mod.rs:1172`;
   fx/midi/drums обёрнуты `mod.rs:1157-1169`, params обёрнут на `mod.rs:1212`), dock
   регистрируется раньше (`mod.rs:1079`). На экране: между zone-баром и "Master"
   пусто, ни заголовка, ни индикатора (`/tmp/z3_hdr.png`). — CONFIRMED
2. **Хоткей `X` очищает лупер сразу; кнопка Clear в GUI спрашивает «Sure?»**
   (`src/gui/keybinds.rs:44` → `mod.rs:1551` против `drums.rs:808-825`). Одно и то же
   деструктивное действие — подтверждение только на одном пути. — code-verified
3. **Смешение RU/EN в панели партий**: «Split: вкл», «+ Добавить парт», «◀ Левая рука (A) —
   0..59» в остальном английском UI (`layers.rs:37,41,124,126,139,158`, `drums.rs:872`). — CONFIRMED
4. **Подписи осей XY-пада макросов вообще не рендерятся** — рисуются вне clip-rect:
   `rect.bottom()+10` и `rect.left()-4` под `painter_at(rect)` (`macros.rs:136,182-196`).
   Пользователь не видит, какой макрос на какой оси. — code-verified

## Medium (контраст — посчитан)

Примечание: WCAG 1.4.11 исключает truly-disabled контролы, но все перечисленные
muted/off-состояния — состояния активных кликабельных контролов, 3:1 обязателен.
Порог текста 4.5:1 применяется ко всему тексту <18pt — льгот для 9–13px нет.

5. **Приглушённые/неактивные состояния ниже 3:1**:
   - Key-zone map, неактивная партия: композит `c/2` alpha-180 поверх BG_PANEL ≈ (33,55,79)
     на (27,27,27) = **1.37:1** (экранный сэмпл (44,74,109) давал 1.89:1 — по коду ещё хуже) —
     зона сплита B1 почти невидима рядом с активной A1 (`layers.rs:519-528`). — CONFIRMED
   - Pitch-seq gate-off ячейка gray(50) на gray(30) = **1.30:1** (`theme.rs:179`,
     `drums.rs:748-753`) — практически недостижимо из-за п.1. — not screen-verified
   - Muted-слой лупера gray(80) = **2.1:1** (`drums.rs:1040-1069`); точки muted-слоёв в
     таймлайне alpha-40 = **1.2–1.3:1** (`drums.rs:1176-1183`). — not screen-verified
   - MIDI-seq mute «M» gray(80) = **2.1:1** (`midi_seq.rs:159-165`); Loop-off DARK_GRAY
     = gray(40) = **≈1.15:1** (`midi_seq.rs:35-40`). — not screen-verified
   - Текст диапазона сплита `.weak()` ≈ gray(100) = **2.9:1** при 13px («— 0..59» едва
     читается) (`layers.rs:391-393`). — CONFIRMED
   - Pad-perf: нижний ряд пэдов к пустому фону **2.22:1**; имя перфа белым на бирюзовом
     **3.14:1 при 11px** (`settings.rs:54-83`). — not screen-verified
6. **Состояние только цветом (WCAG 1.4.1)**: MIDI-seq Mute (жёлтая/серая буква) и Loop
   (зелёная/серая) без второго признака; то же у S/M слоёв лупера; mute партии в Layers —
   только GRAY-метка (`layers.rs:307-313`). — code-verified
7. **Видимость значений**: слайдеры L/T/D/P барабанов (40px, `show_value(false)`) нигде не
   показывают значение (`drums.rs:276-292`). — CONFIRMED (`/tmp/z_grid_s.png`)
8. **Instrument browser — полноэкранная модалка для обратимого выбора** (`mod.rs:1233`);
   модалки remap — тот же паттерн (`drums.rs:444,534`). Модальность в egui сама по себе
   идиоматична (`egui::Modal`); претензия — к полноэкранности и применению к обратимому
   выбору. Settings/Pad-perf правильно используют окна. — not screen-verified
9. **Несогласованность подтверждений деструктивных действий**: три механизма — модалка
   (удаление партии, `layers.rs:174`), таймер «Sure?» (Clear лупера) и сразу без подтверждения:
   drum Clear, FX Reset, pad-perf right-click clear, unbind биндинга, Reset Defaults
   (`drums.rs:72`, `fx_chain.rs:14`, `settings.rs:93`, `mod.rs:1619,1630`). Плюс п.2 обходит
   единственную существующую защиту. — частично CONFIRMED
10. **Две палитры барабанов**: пэды — захардкоженные цвета категорий (`keyboard.rs:145-157`:
    snare=(85,185,95) зелёный, hats=(212,200,70) жёлтый), степ-грид — `theme::DRUM_COLORS`
    (`theme.rs:212`: snare=(220,140,40) оранжевый, Closed HH=(60,180,220) циан) — один
    инструмент, разные цвета в разных видах. — CONFIRMED
11. **Pitch-метки 9px gray(180), 1.43:1 поверх синего бара** (`drums.rs:721-730`); обрезаются
    при pitch=+24 (`painter_at` на `drums.rs:667`). — code-verified

## Low

- Границы ячеек drum-грида gray(90) против заливок битов = 1.86–2.36:1. — CONFIRMED
- Имена треков MIDI-seq обрезаются на 23 символа без tooltip (`midi_seq.rs:182-188`);
  метки pad-perf 10 символов, без tooltip (`settings.rs:76-85`).
- FX-chain ↑/↓: ~20px соседние цели, меняющие порядок без подтверждения (`fx_chain.rs:49-53`).
- Note-on на белых клавишах 1.64:1, без неколорового признака (`keyboard.rs:84-89`).
- Красный «errs 1» в top bar без возможности узнать, что за ошибка (`mod.rs:909`).
- Mute — 3 стиля виджетов, boolean-тумблер — 4 стиля, заголовки секций — 3 приёма
  (layers.rs:375 / drums.rs:1087 / midi_seq.rs:165; mod.rs:930 / drums.rs:930 / midi_seq.rs:40 / drums.rs:83).
- «Reset» означает 5 разных вещей; откат патча — «Reset» в одном месте и «Init» в соседнем
  (`mod.rs:1192` против `params.rs:1665`). «Layer» = дубль лупера в UI, = партия в layers.rs/конфиге.
- Раздельные представления предупреждений: toast (`settings.rs:462`) vs жёлтая inline-метка
  (`macros.rs:127`); «Restart to apply» дважды в одном флоу (`settings.rs:660,668`).
- Отступы/константы: `Margin::same(6)` ×10 в params.rs (вне шкалы 2/4/8/12), 5 вариантов
  grid-spacing, `slider_width = 250.0` литералом вместо SLIDER_PRIMARY (`mod.rs:497`).
- «+ Добавить парт» small_button рядом с full-size кнопкой в том же ряду. — CONFIRMED

## Не проверялось

- Scale survival (Ctrl+scroll 0.75–1.5×).
- LED-консоль (аппаратный medium): цветовое кодирование по дизайну, на экран не выведено.

## Quick wins

1. Поднять 4 константы ниже 3:1 (`SEQ_GATE_OFF`, `LOOPER_LAYER_MUTED`,
   `MIDI_SEQ_MUTE_INACTIVE`, alpha неактивных зон) — только theme.rs.
2. Рисовать подписи осей XY-пада через `ui.painter()` вместо обрезаемого `painter_at` (macros.rs).
3. Англоязычные метки панели партий (layers.rs).
4. Хоткей `X` через тот же 2s-confirm, что и кнопка Clear.
5. Значение по hover для L/T/D/P слайдеров (tooltip для disabled уже есть — дополнить значением).

## Strategic (по порядку, с зависимостями)

1. Унифицировать muted-gray / error-red / toggle-on-green в theme — без зависимостей; закрывает
   4 находки.
2. ScrollArea для default-ветки central или перенос Step Sequencer в dock — зависит от решения
   по dock-раскладке (TECHDEBT #30); закрывает High п.1.
3. Один механизм подтверждения деструктивных действий (взять таймер «Sure?» — живой режим;
   модалки оставить для удаления партии) — без зависимостей.
4. Единый источник цветов барабанов (категории пэдов из DRUM_COLORS) — без зависимостей.
5. Модалки instrument browser + remap → немодальные окна — без зависимостей.
6. Второй признак состояния для mute/loop/solo (вес/зачёркивание/иконка) — зависит от п.1.

## Decline (отклонено, с причинами)

- Направляющие линии 1.70:1 — декоративные, не интерактивные.
- Кастомные гриды/пэды только мышью — осознанно для hardware-first живого инструмента;
  хоткеи покрывают transport и корректно уступают текстовым полям (`mod.rs:594-607`).
- `Margin::same(6)` в params.rs отдельно — внутри файла консистентно; в общую зачистку шкалы.
- Toast-цвета вне theme (mod.rs:1126) — косметика до theme-унификации.
- Looper Clear disabled без tooltip — причина очевидна из пустого лупера.
